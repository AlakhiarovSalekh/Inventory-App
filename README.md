# Inventory Management Desktop App

[![Python](https://img.shields.io/badge/Python-Desktop-3776AB?logo=python&logoColor=white)](https://www.python.org/)
[![PyQt5](https://img.shields.io/badge/PyQt5-GUI-41CD52?logo=qt&logoColor=white)](https://www.riverbankcomputing.com/software/pyqt/)
[![Stars](https://img.shields.io/github/stars/AlakhiarovSalekh/Inventory-App?style=social)](https://github.com/AlakhiarovSalekh/Inventory-App/stargazers)

A desktop inventory-management application built with Python and PyQt5. The repository is organized around common business workflows including stock, orders, suppliers, billing, pricing, and contact management.

## Modules

- **Homepage** — main application area
- **Stock** — inventory/stock workflows
- **Orders** — order management
- **Suppliers** — supplier management
- **Billing** — billing-related workflows
- **Pricing** — pricing screens and logic
- **Contact** — contact-related functionality

## Tech Stack

- Python
- PyQt5 / Qt Designer UI files
- SQL database resources
- Qt resource files

## Getting Started

Clone the repository:

```bash
git clone https://github.com/AlakhiarovSalekh/Inventory-App.git
cd Inventory-App
```

Install the Python dependencies required by the source, configure the database from `ims.sql`, then start the application from `main.py` after the local database configuration is ready.

## Why this project

This repository is a practical example of building a multi-screen business desktop application with Python, Qt UI files, SQL-backed data, and separate functional modules.
